Nova Worker را نصب کن

فقط توکن کلودفلر را وارد کن؛ Worker، فضای KV و رمز مدیریت روی حساب خودت ساخته می‌شود.

Cloudflare Workers KV خودکار پنل فارسی بدون هزینه

من توکن دارم — نصب پنل

اگر توکن API کلودفلر را از قبل ساخته‌ای، همین‌جا بچسبان و نصب را شروع کن. Worker و KV روی حساب خودت ساخته می‌شود.

تنظیمات پیشرفته

اگر توکن به چند حساب دسترسی دارد یا فهرست حساب‌ها نمایش داده نمی‌شود، شناسهٔ ۳۲ کاراکتری حساب را اینجا وارد کن.

توکن فقط در حافظهٔ همین مرورگر می‌ماند و برای نصب به api.cloudflare.com فرستاده می‌شود؛ ذخیره نمی‌شود. بعد از نصب می‌توانی توکن را Revoke کنی.

هنوز توکن ندارم

یک توکن موقت با حداقل دسترسی لازم بساز. بعد از نصب می‌توانی همان توکن را از داشبورد کلودفلر حذف کنی.

  • Workers Scripts — Edit
    آپلود و انتشار Worker
  • Workers KV Storage — Edit
    ساخت فضای KV و ذخیرهٔ تنظیمات
  • Account Settings — Read
    خواندن نام حساب (اختیاری ولی مفید)
  1. روی دکمهٔ زیر بزن؛ صفحهٔ ساخت توکن کلودفلر با دسترسی‌های لازم از قبل تیک‌خورده باز می‌شود.
  2. فقط «Continue to summary» و بعد «Create Token» را بزن — چیزی را دستی انتخاب نکن.
  3. توکن را کپی کن، برگرد اینجا، در کارت سمت راست بچسبان و نصب را شروع کن.

این توکن فقط برای نصب لازم است. بعد از گرفتن لینک ورود و رمز، از My Profile → API Tokens همان توکن را Revoke کن.
